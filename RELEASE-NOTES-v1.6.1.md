# Release v1.6.1

## Highlights
- **Typing Speed in the HUD**: A words-per-minute counter in the HUD's corner, with a graph of the last 30 seconds, like ZMK's WPM widget on the nice!view. Five key presses make a word, averaged over the last five seconds; layer and keyboard keys don't count. It shows while the keyboard is connected and can be turned off in Settings → HUD Appearance.

## Documentation
- The README starts with a setup guide: a quick start with your `.keymap` file, or the full setup with ZMK Studio step by step.
- A GIF of the HUD shows keys lighting up, layers switching and the typing speed.
- Adds the MIT `LICENSE` file and credits the projects the live layer and reading the keymap build on.
